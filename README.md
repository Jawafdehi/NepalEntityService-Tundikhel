# NES Tundikhel — Nepal Entity Service Explorer

> ## ⚠️ This repository is archived
>
> Tundikhel has been **superseded by the consolidated Jawafdehi platform**. Browsing and searching Nepali public entities is now part of the unified Jawafdehi web application at [jawafdehi.org](https://jawafdehi.org). This repository is kept for history only — it is no longer maintained and receives no further changes.

This was a React + TypeScript + Vite application for exploring the [Nepal Entity Service](https://github.com/Jawafdehi/NepalEntityService) database. Its functionality has moved into the main Jawafdehi web app.
